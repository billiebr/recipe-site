# ספר המתכונים שלי

אתר מתכונים משפחתי עם סיסמה אחת לכל המשפחה. רץ על Netlify:
- `public/` – האתר עצמו (עמוד אחד, עובד בטלפון ובמחשב, אפשר להוסיף למסך הבית).
- `netlify/functions/recipes.mjs` – שמירה, עריכה ומחיקה של מתכונים. בודק את הסיסמה בכל בקשה.
- `netlify/functions/import.mjs` – קריאת מתכון מלינק: פותח את הדף וממלא את השדות.
- `data/seed.json` – מתכונים שנוספו או נערכו דרך Claude. האתר מעתיק אותם לאחסון שלו אחרי כל Deploy.

המתכונים נשמרים ב-Netlify Blobs, האחסון המובנה של Netlify, בלי שירות נוסף.

## חיבור ל-Netlify (פעם אחת)
1. ב-Netlify: **Add new site → Import an existing project → GitHub**, ובוחרים את `billiebr/recipe-site`.
2. **Branch to deploy:** `main`
3. שאר השדות נשארים כמו שהם (Netlify קורא אותם מ-`netlify.toml`).
4. לפני ה-Deploy, תחת **Environment variables**, מוסיפים `FAMILY_PASSWORD` עם הסיסמה המשפחתית.
5. Deploy. אפשר לשנות את שם האתר תחת **Site configuration → Change site name**.

כדי להחליף סיסמה: משנים את `FAMILY_PASSWORD` ועושים Deploy מחדש. מי שהיה מחובר יתבקש להקליד את הסיסמה החדשה.

## שתי דרכים לעדכן מתכונים
- **באתר:** כפתור "מתכון חדש", "עריכה" ו"מחיקה". נשמר מיד.
- **דרך Claude:** Claude מוסיף או מעדכן מתכון ב-`data/seed.json` ודוחף ל-GitHub. Netlify בונה את האתר מחדש, והמתכון מופיע תוך דקה או שתיים.

כללים ב-`data/seed.json`:
- כל מתכון מועתק לאתר פעם אחת בלבד. אם מתכון נמחק באתר, הוא לא חוזר.
- כדי לעדכן מתכון קיים מגדילים את `rev` שלו (ברירת המחדל היא 1). העדכון דורס את הגרסה שבאתר, כולל שינויים שנעשו באתר.
- כדי למחוק מתכון מוסיפים `"deleted": true` ומגדילים את `rev`.

## הוספת מתכון מלינק
ב"מתכון חדש" מדביקים לינק ולוחצים "קרא את המתכון". הטופס מתמלא, בודקים ושומרים.

- **בלי הגדרה נוספת:** עובד באתרים שמסמנים את המתכון בדף (רוב אתרי המתכונים). הטקסט נשאר בשפה של האתר, והקטגוריה נבחרת לפי מילות מפתח.
- **עם מפתח Gemini משלך** (מפתח חינמי מ-aistudio.google.com), שנשמר ב-Netlify במשתנה ששמו מתחיל ב-`GEMINI_API_KEY_` (למשל `GEMINI_API_KEY_recepies`): Gemini קורא גם דפים בלי סימון, מתרגם לעברית ובוחר קטגוריה. ברירת המחדל היא `gemini-flash-lite-latest`, ואפשר להחליף מודל עם `GEMINI_MODEL`.
- **בלי מפתח משלך:** Netlify מזריק לבד מפתח של AI Gateway (`GEMINI_API_KEY`), והקריאה עוברת דרכו ונספרת בקרדיטים החודשיים של חשבון Netlify.
